In case using a server hosted on http, and you want to call it via a browser app running on https, and you cannot add a proper certificate on the server to run it on https, the quickest resolution is to use `ngrok` on the server side. `ngrok` will provide the certificates required and after whitelisting origins, you can easily use in your application
2. How to use smartcrop and spread an image to occupy full width:
	https://s7ap1.scene7.com/is/image/varun?layer=0&rotate=0&size=250,150&pos=0,0&opac=100,100&hide=0&color=0xffffffff&layer=1&rotate=0&size=250,150&pos=0,0&opac=100,100&hide=0&src=is(varun/back1:150?wid=250&hei=150)
	
    Here i wanted to fully fill the canvas which does not happen with: https://s7ap1.scene7.com/is/image/varun?layer=0&rotate=0&size=250,150&pos=0,0&opac=100,100&hide=0&color=0xffffffff&layer=1&rotate=0&size=250,150&pos=0,0&opac=100,100&hide=0&src=is(varun/back1:150) because the dimensions of the smart cropped image are: 150x100 which does not match 250x150. so i use `?wid=250&hei=150` at the end  to get my desired image that fills the bounding box i want.
